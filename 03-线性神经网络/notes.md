# 第 03 章学习笔记：线性神经网络

## 本章目标

- 理解线性回归如何从数据中学习权重和偏置。
- 理解小批量随机梯度下降的基本步骤。
- 能区分模型、损失函数和优化算法。
- 用 Notebook 观察每个阶段，用 Python 文件做可重复验证。

## 当前实现

本次只整理“线性回归的从零开始实现”这一条代表性学习路径，不建立节级目录。

核心流程：

1. 用已知参数和随机噪声生成合成数据。
2. 将数据随机打乱并划分为小批量。
3. 初始化权重和偏置。
4. 计算均方损失。
5. 反向传播求梯度。
6. 使用小批量随机梯度下降更新参数。
7. 比较学习参数与真实参数，并检查损失。
